## Strategy before automation

It is easy to start with an AI tool. A demo looks good, someone signs up, and the tool gets connected to the way the business runs today. Then it runs today's process faster, including the steps that should not exist.

This kit starts with the business instead. It frames the problem before it picks a solution, and it works in one order: name the limit, cut, build one engine, prove it with checks. This page is for the owner and for the owner's agent. The agent reads it before the first conversation.

## Name the limit first

What is holding the business back right now: finding buyers, turning them into sales, the offer and its price, getting the work delivered, or cash? Name one, from the business's own records, before anything gets built. If the records cannot show which one, the answer is `UNKNOWN`, and the first job is to find out. Next: open The Operator Check at the front of this kit. It will use the owner's records to name one constraint and draft the next four weeks.

## Cut before you build

With the limit named, look at the work around it, one step at a time. Ask whether the step needs to happen at all. If it does not, remove it. If it stays, make it simpler, then quicker. Only what is left is a candidate to automate or hand to someone else.

A step you remove needs no tool, no prompt and no one to run it.

## Build one engine

Here an engine is one repeatable way of doing a piece of work: written down so a person or an agent can run it, with one owner and one check. Build the engine aimed at the current limit. A second one waits until the first runs and its check passes.

## Prove it with checks

A check is something another person can run and get the same reading. It also needs a way to fail on purpose, because a check that has never failed has not shown it can see anything. A business number needs a source, a period and a unit. Without them it stays `UNKNOWN`, and the plan says so.

## The owner decides

The agent reads, asks, drafts and checks. The owner decides. Nothing is sent, spent, deleted, published, installed or changed on a live system without the owner's approval for that exact act.

## For the agent

- Read this page, then `AGENT-INSTRUCTIONS.md` in this folder. Open with the message written there, word for word.
- When you plan, keep this order: the limit, the cuts, the one engine, the checks. If the owner asks for a tool first, help, and say which of those steps is still open.
- Your rules and your authority are in `AGENT-INSTRUCTIONS.md` and `../A01/`. If this page seems to differ from them, follow them and tell the owner what differed.
- When the owner asks why the check starts with the business and not with a tool, point them to this page.

Find the leverage. Build the engine.
