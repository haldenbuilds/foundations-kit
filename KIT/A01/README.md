## Start here

Open the agent you use, give it this whole A01 folder, and paste: `Read AGENT-INSTRUCTIONS.md and help me start.` If you have the Foundations Kit, its manifest opens the same advisor through C09. You can use A01 alone. It needs no account connection, purchase, or other kit folder.

Read `OPERATOR-GUIDE.md` for the owner guide. The agent starts with `AGENT-INSTRUCTIONS.md` and `AGENT-GUIDE.md`. The flow is in `WIZARD.md`; the intake is in `ONBOARDING.md` and `interview.schema.json`; the output shape is in `SCALE-AUDIT-TEMPLATE.md`. `ONGOING.md` runs later sessions. `KIT-GUIDE.md` explains optional kit parts. `wizard.manifest.json` describes the stage records. `gate-check.py` checks package structure when Python is available; it does not judge a business or grant approval.

## What you get

A strategy overview, one evidence-backed constraint, a four-week plan, an offer and money check, and a short scoreboard. Missing evidence stays `UNKNOWN`. You can return for a weekly review, a decision, a task breakdown, or help. Continuing use depends on bringing current records to each session; there is no background monitoring.
