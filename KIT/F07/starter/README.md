# F07 | Reusable project starter

**Row ID:** `F07`

**Built tier:** `fully kitted`

**Purpose:** Reusable project scaffold

**Use after:** F02,F03,F04,F05,F06

## Start here

1. Fill `PROJECT-BRIEF.md` from an owner interview.
2. Put only inspected sources in `sources/`.
3. Keep current state in `STATUS.md`.
4. Put the exact review candidate and receipt in `review/`.

Optional modules stay absent until selected through the dependency plan.
