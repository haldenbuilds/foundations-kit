## How to use

Copy the template table, fill only facts supported by the named sources, and keep unresolved fields as `UNKNOWN`.

## Field notes

| Field | What belongs here |
|---|---|
| Outcome | Describe the observable end state. |
| Inputs | Name files, answers, and systems the task may use. |
| Constraints | Record permissions, exclusions, time, and budget. |
| Proof and handoff | Name checks, output location, and next owner. |

## Safe defaults

- No external action unless named.
- Use UNKNOWN instead of filling factual gaps.
- A failed or unavailable check blocks completion.
